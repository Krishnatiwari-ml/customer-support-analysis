Customer Support Analysis:
A data analysis project exploring customer-support performance using Python, Pandas and Matplotlib.
Objective :
Analyze customer-support activity and performance
Understand call volume and resolution time
Examine customer satisfaction (CSAT)
Identify patterns in customer issue types
Tools:
Python
Pandas
Matplotlib
CSV
Analysis:
Data loading and inspection
Descriptive statistics
Customer-support KPI analysis
Issue-type distribution
Data visualization
Key metrics:
Total calls handled
Average resolution time
Average CSAT
Distribution of issue types
